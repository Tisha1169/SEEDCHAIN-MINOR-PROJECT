# Photography

Photographs supplied by the project owner for SeedChain. They are used as framed, lazy-loaded images (never as a full-page background); the generated vector art in `src/components/art.tsx` remains the fallback if a file is missing.

| File | Source image | Used in |
|---|---|---|
| `harvest.webp` | sunrise potato field | cinematic frame on the landing page (scene 02) |
| `potato.webp` | seedling and potatoes under a planet | "One lot. One identity." (03), QR scene backdrop (04), closing page |
| `farmer.webp` | potatoes above a sunrise valley | farmer digital passport (07), public farmer profile, listing cover |
| `tile-harvest.webp`, `tile-valley.webp`, `tile-seedling.webp` | 960 px versions | marketplace cards, trace page header, customer product card, auth panels |

Only use images you have the right to publish. Keep new files at about 1700 px wide, WebP quality ~75, under ~400 kB.
