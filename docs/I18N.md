# Internationalisation

Languages: English (`en`), Hindi (`hi`, Devanagari), Punjabi (`pa`, Gurmukhi). Library: `i18next` + `react-i18next`.

- Catalogues: `artifacts/seedchain/src/i18n/locales/{en,hi,pa}.ts`. `en.ts` defines the type; the other files must match it, enforced by `locales.test.ts` (same keys, non-English scripts).
- Choice order: saved choice (`localStorage` key `sc.lang`) → browser language → English. `<html lang>` follows the selection.
- Fonts: Noto Sans Devanagari / Gurmukhi (Google Fonts), with ultra-light weights raised so the scripts stay legible.
- Switcher: navbar (public pages, including trace and scan).

## Coverage now
Translated: navbar, public trace page (all labels, errors, verification banner), scanner error states.
**Not yet translated:** landing page copy, marketplace, auth forms, farmer/customer/admin dashboards. They fall back to English.

## Quality note
Hindi and Punjabi strings were written by the assistant and **must be reviewed by native speakers, ideally farmers, before the pilot.** Dates and quantities use the shared formatters; user-entered text (product names, notes) is shown as entered and is not translated.
